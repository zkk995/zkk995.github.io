### 安装 setuptools

下载

```
# 2.7版本 
wget https://bitbucket.org/pypa/setuptools/raw/bootstrap/ez_setup.py --no-check-certificate
# 2.6版本 
wget https://pypi.python.org/packages/source/s/setuptools/setuptools-1.1.6.tar.gz --no-check-certificate
```

安装

```
python ez_setup.py --user
# or sudo install 
sudo python ez_setup.py 
```

### 用pip安装各种包

``` 
sudo yum install atlas
sudo easy_install pip
sudo sudo  pip  install numpy
sudo  pip  install scipy
sudo pip install Matplotlib
sudo pip install scikit-learn
```
