投机解码训练目标设计推理加速GRPO

Acceptance-Aware Draft Model Training for Speculative Decoding

arXiv:2609.24150v1 · 2026-09-21 · Tianhua Xia, Mugilan Ganesan, Yifei Feng, Haiyu Wang, Maximilian Egger, Sai Qian Zhang（纽约大学）

一句话：草稿模型别再绕着 KL 散度「模仿分布」了——贪心解码就用 EAL 损失、采样解码就用 WTV 损失，直接最大化「一段草稿能被目标模型连续接受几个 token」，再叠一层以模拟接受长度为奖励的 GRPO 强化学习，采样温度 T=1.0 时平均接受长度从 5.00 提到 5.76。

一、问题：练了半天，练错了目标

投机解码用小草稿模型一口气猜若干个 token，大目标模型一次前向验证全部。能省多少时间，取决于接受长度——每轮验证平均有几个草稿 token 被放行。

但现有草稿模型训练几乎都在优化交叉熵或 KL 散度，也就是「让草稿的分布贴近目标分布」。论文点出两处错位：

  • 代理错位：草稿模型故意做得很小，根本不可能完美复现目标分布。容量不够时，KL 选中的「整体最像」的解，未必是「最容易蒙对、被接受」的解——而后者才是投机解码真正要的。
  • 机制错位：接受机制随解码方式而变。贪心解码下，草稿 token 等于目标的 top-1 才被接受；采样解码下，接受概率是两个温度缩放后分布的重叠度。一套损失通吃两种机制，注定两头不讨好。

采样解码下单步接受概率有精确表达式（推导自拒绝采样规则）：

atsample=∑vmin⁡{p~t(v),q~t(v)}=1−TV(p~t,q~t)a^{\mathrm{sample}}_t=\sum_{v}\min\{\tilde{p}_t(v),\tilde{q}_t(v)\}=1-\mathrm{TV}(\tilde{p}_t,\tilde{q}_t)

TV 是全变差距离。贪心机制的接受概率则更简单：atgreedy  ≜  qt ⁣(xt⋆),xt⋆=arg⁡max⁡vpt(v)a^{\mathrm{greedy}}_t \;\triangleq\; q_t\!\left(x^{\star}_t\right),\qquad x^{\star}_t=\arg\max_{v} p_t(v)

二、核心：一个模板，两种损失

验证在第一个拒绝处停止，所以窗口内前 k 个 token 全部被接受的概率是逐位接受概率的连乘。长度为 γ 的投机窗口的期望接受长度因此是：

E[Lt]=∑k=1γ∏j=0k−1at+j\mathbb{E}[L_t]=\sum_{k=1}^{\gamma}\prod_{j=0}^{k-1}a_{t+j}

以 γ=3 为例就是：

E[Lt]=at+atat+1+atat+1at+2\mathbb{E}[L_t]=a_t+a_t a_{t+1}+a_t a_{t+1} a_{t+2}

这个「连乘求和」模板就是全文的钥匙：靠前的 token 被拒会连累后面所有 token，损失天然带序列依赖。两种解码机制各实例化一次：

EAL 损失 · 配贪心验证

把每位的接受概率换成草稿分给目标 top-1（即真值 token）的概率，直接最大化连乘和：

WTV 损失 · 配采样验证

把每位的接受概率换成 1−TV(p̃,q̃)，TV 对草稿分布逐段线性、可微，直接求导训练（不再需要 KL 锚定损失）：
LEAL(t)(θ)  ≜  −∑k=1γ∏j=0k−1at+jgreedy\mathcal{L}^{(t)}_{\mathrm{EAL}}(\theta)\;\triangleq\;-\sum_{k=1}^{\gamma}\prod_{j=0}^{k-1}a^{\mathrm{greedy}}_{t+j} LWTV(t)(θ)  ≜  −∑k=1γ∏j=0k−1(1−TV(p~t+j,q~t+j))\mathcal{L}^{(t)}_{\mathrm{WTV}}(\theta)\;\triangleq\;-\sum_{k=1}^{\gamma}\prod_{j=0}^{k-1}\Bigl(1-\mathrm{TV}(\tilde{p}_{t+j},\tilde{q}_{t+j})\Bigr)

两处温度都取推理时实际用的 T，训练目标与部署场景严格对齐。

三、加餐：把接受长度当奖励的 GRPO 阶段

两个代理损失之外，作者再把不可微的接受长度本身当奖励做强化学习，巧妙之处在于全程只需 3 次前向：

① 冻结目标模型
一遍前向得到每个位置的 top-1 序列 x*
② 当前草稿 + 参考草稿
各一遍前向取 argmax，按窗口切片模拟贪心验证，数出各自的接受长度 τ
③ 组内相对优势
同一序列切 G×m 个窗口做组，组内标准化后走 PPO 式裁剪更新

奖励做了去偏：减去参考草稿（SFT 末的快照）在同一窗口的接受长度，前缀难易被抵消，只剩「我比快照强多少」：

R(t)=τπ,(t)−τref,(t)R^{(t)}=\tau^{\pi,(t)}-\tau^{\mathrm{ref},(t)} A(t)=clip⁡ ⁣(R(t)−Rˉgstd⁡(Rg)+ε, −CA, CA)A^{(t)}=\operatorname{clip}\!\left(\frac{R^{(t)}-\bar{R}_g}{\operatorname{std}(R_g)+\varepsilon},\,-C_A,\,C_A\right) LGRPO(g)=−1m∑t∈gmin⁡ ⁣(ρ(t)A(t),  clip⁡ ⁣(ρ(t),1−εclip,1+εclip)A(t))\mathcal{L}^{(g)}_{\mathrm{GRPO}}=-\frac{1}{m}\sum_{t\in g}\min\!\Bigl(\rho^{(t)}A^{(t)},\;\operatorname{clip}\!\bigl(\rho^{(t)},1-\varepsilon_{\mathrm{clip}},1+\varepsilon_{\mathrm{clip}}\bigr)A^{(t)}\Bigr)

GRPO 以 0.1 的权重加在监督损失上，作为 SFT 后 3 个 epoch 的第二阶段。

四、结果：对上机制才有大收益

设置：Qwen3-8B 为目标、Qwen3-0.6B 为草稿，树形投机（深度 7，分支 4/3/2/1/1/1/1，预算 128 节点），5 个基准（MT-Bench / GSM8K / HumanEval / LongWriter / STEM QA），6 万条目标模型生成的 ShareGPT 数据，2 张 H100。下表是平均接受长度：

  • 采样解码下 WTV 大幅领先：T=1.0 时 5.750 对 KL 的 4.998，提升约 15%；T=0.5 也从 4.304 升到 4.780。Gemma4-31B/E2B 链式投机同样验证：T=1 时 WTV 6.102 对 KL 5.699。
  • 贪心解码下 EAL 小幅稳定占优：4.514 对 4.494，增益不大但方向一致；WTV 在贪心下反而略差——训练目标必须与验收机制匹配，跨机制混用两头吃亏。
  • GRPO 是锦上添花：两种机制上都能再榨出一点（+0.01～0.02），且有监督目标是什么它就强化什么。

五、怎么看这篇论文

价值：它把「草稿模型训练目标」从架构改良的阴影里拉出来单独审视，并给出了一条朴实却常被忽略的原则——损失函数应该长成验收机制的样子。WTV 尤其漂亮：从拒绝采样规则出发一步推出接受概率就是 1−TV，顺手得到可微损失，不需要任何额外前向。

边界：实验规模在 8B 目标 / 0.6B 草稿与 31B/E2B 两档；WTV 需要在训练时固定推理温度（换温度要重训或混合训练）；贪心场景下收益温和，真正的甜头在采样解码；GRPO 阶段还需额外超参（组数、裁剪、奖励上限）。

一句话收尾：蒸馏对齐的是「分布」，投机解码要的是「被接受」——下次训草稿模型，先问自己：部署时用贪心还是采样？答案直接决定你该用 EAL 还是 WTV。
