推理蒸馏CoT 重建偏好优化模型安全

FOPL：从「最终答案」反推隐藏思维链，一个重建器通吃所有模型

Learning Teacher Output Preferences from Final Responses for Reasoning Distillation
Hongli Shen, Shaopeng Fu, Qinbo Zhang, Jian Li, Di Wang · KAUST / Stony Brook · arXiv:2611.30338 v1 2026-11-23 · 代码 renmiamu/fopl

一句话：闭源模型把思维链（CoT）藏起来、只给最终答案来防蒸馏，这篇论文证明这些「可见的最终答案」本身就带着教师推理风格的信号——用一个 4B 重建器做 DPO 偏好学习，就能从「问题 + 最终答案」反推出与目标模型风格一致的思维链，训出来的学生在多个基准上追平甚至超过用原生 CoT 蒸馏的效果，而且对训练时从未见过的模型家族同样有效。

1. 问题：藏起来的思维链，还能被「逆向」吗

推理蒸馏的套路很成熟：拿强模型的 CoT 给小模型当训练数据，学生的推理能力显著提升。正因为如此，GPT、Claude、Gemini 这些前沿模型都把原生 CoT 藏起来，只暴露最终答案或简短摘要，防止推理能力被「偷」走。

但藏得住吗？已有工作给出了几条攻击路径：有的利用 API 特性让模型转写加密推理块，有的用自定义工具调用逼出中间推理。与本文最相关的是 Trace Inversion（Zhang et al., 2026）：用一个「代理模型」的原生 CoT 做 SFT，训出一个重建器，从可见的最终答案反推 CoT。问题是——每个目标模型都得单独训一个攻击者，因为不同模型的推理模式（策略、分解方式、记号习惯）差异很大，单一代理上学不到这种差异。

本文问的关键问题是：能不能训一个攻击者，对任意目标模型都能重建出「符合它风格」的 CoT？这要求重建器学会一件事：在不知道目标模型是谁的情况下，判断哪种推理模式和眼前这个最终答案最匹配。

2. 方法：FOPL——用偏好优化学「输出偏好」

核心观察：同一个问题，不同模型给出的最终答案在措辞、结构、强调重点上各不相同，这些可见差异就是推理风格的指纹。要教会重建器利用这些指纹，靠 SFT 模仿是不够的——得让它学会「比较」。FOPL 的做法分三步：

2.1 收集数据

选 K 个 CoT 可见的代理模型（DeepSeek-V4-Pro、Kimi-K2.5、GLM-5.2、Qwen3-235B-A22B-Thinking-2507），对同一批 500 道 HARDTESTS 编程题，每个模型都生成原生 CoT cic_i 和可见最终回答 rir_i。同一道题，四家模型的回答各不相同——这正是监督信号的来源。

2.2 构造偏好对

对每条记录，用重建提示（只含问题和最终回答，不含模型身份）让生成器池产出「合成 CoT」——即答案对得上、但推理过程是别的模型风格的替代品。然后把原生 CoT 设为 chosen、合成 CoT 设为 rejected，在相同的问题-回答条件下配对：

(q,  r,  cnative⏟chosen,  csyn⏟rejected)(q,\;r,\;\underbrace{c^{\text{native}}}_{\text{chosen}},\;\underbrace{c^{\text{syn}}}_{\text{rejected}})

关键设计：偏好对固定了问题和最终回答，只让推理过程不同。重建器要赢得比较，就必须学会从最终回答的可见特征反推「哪种推理过程更可能产出这样的回答」。

2.3 DPO 训练

用标准 DPO 目标把所有代理的偏好对池在一起，训一个重建模型（Qwen3-4B），全程不给模型身份信息：

LDPO(πθ)=− E(q,r, c+, c−)[log⁡σ ⁣(βlog⁡πθ(c+∣q,r)πref(c+∣q,r)−βlog⁡πθ(c−∣q,r)πref(c−∣q,r))]\mathcal{L}_{\mathrm{DPO}}(\pi_\theta) = -\,\mathbb{E}_{(q,r,\,c^{+},\,c^{-})}\left[\log \sigma\!\left(\beta \log \frac{\pi_\theta(c^{+}\mid q,r)}{\pi_{\mathrm{ref}}(c^{+}\mid q,r)} - \beta \log \frac{\pi_\theta(c^{-}\mid q,r)}{\pi_{\mathrm{ref}}(c^{-}\mid q,r)}\right)\right]

训练完成后冻结参数，对任意目标模型只用「问题 + 可见最终回答」就能重建 CoT：

c^=Rθ(q,r)\hat{c} = R_\theta(q, r)

对比基线 Trace Inversion 的 SFT 目标 min⁡θ−E[log⁡πθ(c∣q,r)]\min_\theta -\mathbb{E}[\log \pi_\theta(c\mid q,r)] 只教「模仿」，不教「分辨」——这是后面消融实验的核心对照。

3. 实验：风格对得上，蒸馏还更强

3.1 实验设置

  • 重建器：Qwen3-4B；下游学生：Qwen2.5-1.5B-Base；
  • 偏好训练家族：DeepSeek、Kimi、GLM、Qwen 四家；MiMo 作为 held-out 家族，训练时完全不可见，用来测泛化；
  • 评估两条线：①重建 CoT 是否像目标模型的原生推理（LLM-as-a-judge，Gemini 3.8 Flash 主判，GPT-5.6-Luna 复核）；②重建 CoT 蒸馏出的学生是否好用（GSM8K、MATH-500、GPQA、OpenBookQA、AdvBench 安全性）。

3.2 相似度：对角优势，包括没见过的 MiMo

把「参考家族的原生 CoT」固定，只换条件化用的最终回答来源，让裁判二选一。结果呈现干净的对角优势：

最有说服力的是 MiMo 那一行：它从未参与偏好训练，但用它的回答做条件化，重建结果仍以 60.51% 的胜率更像它的原生 CoT。这说明重建器学到的不是「四个训练家族的风格速查表」，而是从最终回答的可见线索泛化出来的风格匹配能力。裁判换成 GPT-5.6-Luna 复核，对角结构不变（两裁判一致率 70.05%）。

三个要点：

  • 全面胜过提示合成：四个回答来源上，FOPL 的平均提升（+18.07 ~ +23.35）都是重建方法里最高的，且在 GSM8K、MATH-500、GPQA 上全部领先，不是靠某个任务或某个来源撑起来的；
  • 12/12 胜过 Trace Inversion：与 SFT 路线的现有方法对比，FOPL 在 3 个来源 × 4 个基准上全胜（例如 DeepSeek 来源下 GSM8K 57.85 vs 28.51）；
  • 常常超过原生 CoT：12 组对比里 10 组（GSM8K/MATH-500/GPQA）FOPL 反超 oracle——作者的解释是原生 CoT 只是教师「原始输出偏好」的参考，不是学生性能的上界；但 AdvBench 安全性上原生 CoT 在 4 组里赢 3 组，优势不均匀。

对闭源模型的迁移测试：对 GPT-5.6-Luna（原生 CoT 完全不可得），FOPL 相比「只用最终回答蒸馏」在 GSM8K 和 MATH-500 上分别提升 8.93 和 6.40 个百分点。

3.4 消融：偏好学习到底贡献了什么

  • DPO vs SFT：同样的原生 CoT 当正例，SFT 只学模仿，DPO 额外用合成 CoT 当负例。下游学生五个基准全涨（+2.42 ~ +16.70 pp），风格匹配胜率也全面更高——「学会分辨」比「学会模仿」值钱，且 held-out 的 MiMo 上差距最大（+6.93）；
  • 去掉重建、只给最终回答：学生表现明显更差，说明收益来自「把最终回答里的信息转化成结构化推理示范」，而不是单纯多见了教师的可见输出；
  • 数据规模：1250 条（25%）重建数据就能全面超过基座，5000 条基本到顶——重建监督的数据效率不错。

4. 点评：克制的好论文，以及它的双刃剑属性

值得肯定的地方

  • 问题定义干净：从「每个目标单独训攻击者」推进到「一个攻击者通吃」，且不依赖 API 特性或提示注入，只靠公开可见的输入输出——这是对威胁模型更现实的刻画；
  • 方法极简：没有新架构、新损失，就是把 DPO 的「比较结构」用对了地方——固定问题与回答、只变推理过程，让偏好信号精确对准「风格匹配」这一个维度；
  • 行文罕见地克制：作者反复强调重建的 CoT 不是目标模型内部推理的逐字记录，只是「与可见输出兼容的重建」，MiMo 的结果也只解读为「证据」而非「证明」。这种不越界的写法在攻击类论文里不多见。

局限与值得追问的

  • 评估依赖 LLM-as-a-judge：相似度结论由裁判模型说了算，虽然做了双裁判鲁棒性检验（一致率 70%），但「风格像」本身是个软指标，70% 的一致率意味着相当一部分判断在裁判之间摇摆；
  • 「超过原生 CoT」需要谨慎解读：原生 CoT 在安全性上仍占优，且 FOPL 反超的场景集中在数学/科学推理——更可能是重建轨迹更「规整易学」，而非真的比原生推理更有信息量；
  • 防御侧的启示同样重要：这篇论文等于量化了「最终回答泄露推理风格」的程度——对齐、安全团队应该把「可见输出的风格指纹」纳入防蒸馏的威胁模型。只藏 CoT 不改最终回答的呈现方式，防不住这类攻击；
  • 偏好对构造的规模：训练只用 500 道编程题 × 4 家代理，规模不大却足够泛化，说明「比较信号」的样本效率确实高于「模仿信号」，这一点对做偏好学习的人也有独立参考价值。

整体看，这是「CoT 重建」这条线上把模型无关性补齐的工作：Trace Inversion 证明了能反推，FOPL 证明了能泛化。对做蒸馏的人来说，闭源教师的 CoT 从此多了一条不依赖任何 API 漏洞的获取路径；对做模型安全的人来说，这是一份值得认真对待的攻击面测绘报告。
