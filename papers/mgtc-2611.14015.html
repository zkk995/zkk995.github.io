Margin-Guided Token Credit for Reinforcement Learning with Verifiable Rewards

arXiv:2611.14015v1 · 2026-11-10 · Chi Liu, Xin Chen, Yuchuan Weng, Srinivasan Manoharan（PayPal.AI）· 方法名 MCPO

一句话：GRPO 把整条回答的组优势平均摊给每个 token——3,000 token 的推导里，「Let」和「=」与决定胜负的那一步拿得一样多。MCPO 用策略自身分布的 top-2 差距 M=p₁−p₂ 衡量"这个位置有多犹豫"，固定阈值映射成分数，把优势重新分摊：正优势多分给犹豫处，负惩罚多压到自信处；margin 从 trainer 本就要跑的旧策略前向里白拿，零额外前向、零批内统计。MiniCPM5-2B 上 5 个数据种子全部赢过 GRPO，平均 +6.55 分（macro avg@32，CI [+4.1, +9.0]）。

一、问题：GRPO 的信用是「大锅饭」

RLVR 用可验证奖励（答案对错）训推理模型，GRPO 是当前最常用形式：对同一题采 G 条回答，组内标准化出优势，然后丢进裁剪代理损失：

L=−1∑i∣oi∣∑i∑tmin⁡(ρi,tAi,t, clip(ρi,t,1±ε)Ai,t)\mathcal{L}=-\frac{1}{\sum_{i}|o_{i}|}\sum_{i}\sum_{t}\min\big(\rho_{i,t}A_{i,t},\ \mathrm{clip}(\rho_{i,t},1\pm\varepsilon)A_{i,t}\big)

plain GRPO 里 Ai,t = Ai，每个 token 拿同样的优势。改进方向里最活跃的一支是用熵找关键 token：只训最高熵的 20% token（forks 论文）、把熵加进优势、按熵比分配奖励、对高低熵 token 区别约束等。但论文点出熵的两个毛病：

  • 熵度量整个分布的铺开程度，不是决策的胶着程度：一个「有明确赢家 + 长而平的尾巴」的位置熵可以很大，但下一个 token 根本没有悬念。合成实验：同一条 margin 附近，熵能差好几个 nat（图 2）。
  • 归一化依赖批：熵数值难跨位置比较，大多数方法要做批内/组内分位数归一化——同一个分布，落在犹豫多的批里分数高，落在自信的批里分数低，信用随「批里还采了什么」漂移。

作者换成主动学习里老掉牙的 margin 准则：在每个位置只问一个问题——前两名有多接近？

二、方法：top-2 差距 + 固定阈值 + 均值不变的分摊

margin 分数

取策略（温度缩放后）下一个 token 分布的两个最大概率，定义分数 h：

M=p1−p2,h=clip((1−M)−ℓu−ℓ, 0, 1),ℓ=0.1, u=0.7M=p_{1}-p_{2},\qquad h=\mathrm{clip}\Big(\frac{(1-M)-\ell}{u-\ell},\,0,\,1\Big),\qquad \ell=0.1,\ u=0.7

M ≥ 0.9 → h=0（毫无悬念），M ≤ 0.3 → h=1（真正的两难），中间线性过渡。阈值是绝对的：margin 0.9 在任何批里都得分 0，不随训练阶段或同伴漂移——代价是两个不自适应的超参，论文全程用一套没调过的 ℓ=0.1、u=0.7。

把优势摊下去（均值不变）

沿用 Yeo et al. (2026) 的加权规则，把它的「批分位数归一化熵」换成 margin 分数：

Ai,t=Ai eκ sign(Ai) hi,t1∣Ti∣∑t′∈Tieκ sign(Ai) hi,t′,κ=ln⁡4A_{i,t}=A_{i}\,\frac{e^{\kappa\,\mathrm{sign}(A_{i})\,h_{i,t}}}{\frac{1}{|T_{i}|}\sum_{t'\in T_{i}}e^{\kappa\,\mathrm{sign}(A_{i})\,h_{i,t'}}},\qquad \kappa=\ln 4

κ=ln 4：同一回答内两个 token 的原始权重最多差 e^κ=4 倍。除以组内均值保证 每个回答的平均 token 优势仍是 A_i——整体奖惩规模不变，只是内部重新分配：

正优势（做对了）
犹豫处（h 大）多拿奖励——推理岔路口被强化
负优势（没做对）
自信处（h 小）多背惩罚——岔路口不被连坐

负优势 ≠ 答错：奖励里还含 DAPO 软超长惩罚，答对了也可能整体为负。例子：一条回答三个位置的 margin 是 (0.98, 0.60, 0.20) → h=(0, 0.5, 1) → 权重 (1, 2, 4)。正优势时三处分到 A·(0.43, 0.86, 1.71)；负优势时反过来 A·(1.71, 0.86, 0.43)。

成本：约等于零

trainer 为校正 vLLM 采样器本来就要对 rollout 跑一遍旧策略前向——把这一次调用的 log-softmax 包一层，顺手记下每个位置的 top-2 概率即可。没有额外模型评估、没有额外 rollout、不依赖任何批统计。bf16 精度下 margin 偏差约 2×10⁻³（130K 词表实测）。

四、怎么看这篇论文

价值：工程性价比极高的一招——不引入新模型、新标签、新采样，只从策略自己的分布里读一个标量；margin 逐位置可比，绕开了熵系方法普遍依赖的批内归一化。它没有说 margin 一定比熵好，只说「比均匀信用好」，定位诚实。写作也罕见地坦白：Limitations 里逐条列出没做的熵基线、没做的随机分数对照、没分离的长度效应。

边界：只比了 200 步 LoRA 的 plain GRPO，两个 GRPO run 答案塌缩到极短，说明部分增益可能是「不让训练崩向超短回答」而非信用分配本身；Qwen 侧种子太少；回答变长 2–3 倍意味着推理成本同步上涨；margin 与熵哪个是更好的犹豫度量，留给后续。

一句话收尾：熵问「分布多铺开」，margin 问「前两名多接近」。犹豫处才是推理的岔路口——奖励多给岔路口，惩罚别打岔路口。
