在灵光里，一键唤醒高德导航

从"聊天链接全变下载页"到"点卡片一秒唤起高德"——一次把问题摸到底的记录，含模版与可直接复用的 Prompt。

★问题：链接好好的，为什么打不开

最初的需求很朴素：跟助理说一声目的地，手机上直接开始导航。结果在聊天里点 uri.amap.com 的导航链接，永远被带到一个"下载高德App"的页面。

原因后来摸清了：在支付宝里点任何链接，都会先进支付宝内置浏览器。这个浏览器不允许网页唤起其他App，高德的跳转链接自然全被拦下。聊天里换链接、换参数、换 amapuri:// 协议头，都出不去这个房间。

★实测结论

打开方式结果
聊天内直接点 uri.amap.com 链接被拦成下载页 ✗
聊天内点 amapuri:// 协议链接无法识别，无响应 ✗
系统浏览器（Safari）打开同一条链接正常唤起高德 ✓
页面卡片 → 点页内「网页版导航」按钮正常唤起高德 ✓（最终采用）

结论：问题不在链接，在打开链接的容器。把链接装进一个独立网页、以卡片形式交付，让网页在系统浏览器里打开，跳转就通了。

★方案：一键导航页

做一个极简的单文件网页：大字目的地、一行地址、三个按钮。

  • 开始驾车导航：https://uri.amap.com/navigation?to={经度},{纬度},{URL编码名称}&mode=car&src=lingguang&coordinate=gaode&callnative=1
  • 公交/打车方案：同上，mode=bus
  • App直连（系统浏览器内有效）：amapuri://route/plan/?dname={名称}&dlon={经度}&dlat={纬度}&dev=0&t=0

注意：名称必须做 URL 编码（中文原样塞进链接会直接失效），坐标用高德 GCJ02。

★做成模版：换个目的地只要十秒

把上面的页面抽成模版，留四个占位符，批量生产：

占位符含义示例
{{NAME}}目的地名称上海虹桥国际机场
{{NAME_ENC}}名称的 URL 编码%E4%B8%8A%E6%B5%B7…
{{LNG}} / {{LAT}}高德坐标121.339775 / 31.196029
{{ADDR}}一行地址上海市长宁区虹桥路2550号

生产流程固定三步：查坐标 → 套模版 → 发布成卡片。已跑通两个案例：蚂蚁S空间（浦东）、虹桥机场。

★可复用 Prompt

没有我的环境也行，把下面这段发给任何 AI 助手，改开头三行就能用：

帮我做一个"一键唤起高德导航"的手机网页并交付文件卡片。
目的地：{{名称}}，地址：{{地址}}，高德坐标(GCJ02)：{{经度}},{{纬度}}

硬性要求：
1. 单文件 HTML，手机全屏适配，深绿底白字、大按钮，不用任何外部依赖和JS。
2. 页面含三个按钮：
   - 主按钮"开始驾车导航"：https://uri.amap.com/navigation?to={{经度}},{{纬度}},{{URL编码的名称}}&mode=car&src=lingguang&coordinate=gaode&callnative=1
   - 次按钮"公交/打车方案"：同上但 mode=bus
   - 备用按钮"App直连"：amapuri://route/plan/?dname={{URL编码的名称}}&dlon={{经度}}&dlat={{纬度}}&dev=0&t=0
3. 页面底部注明：需在Safari等系统浏览器打开，支付宝/微信内会被拦截。
4. 背景原因：聊天内裸链接会被支付宝内置浏览器拦成下载页，必须走页面卡片。

注意：URL编码后的名称不要中文原样塞进链接。

★一句话总结

别在聊天里赌链接，把链接装进页面里发。容器对了，高德一秒就醒。
